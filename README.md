# FWL Travels & Tours

Premium React + TypeScript + Tailwind CSS travel agency landing page.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Replace later

- Image URLs are centralized near the top of `src/App.tsx`.
- Booking/search and contact form are frontend demonstrations only.
